# 评测方案

## 评测分层

退货 Agent 不应只评测“回答像不像”。至少分五层：

1. 政策检索；
2. 资格判断；
3. 对话补槽；
4. 受控写入；
5. 安全与故障恢复。

## 当前自动化用例

运行：

```bash
python -m unittest discover -s test -v
```

黄金规则用例位于 `data/eval/return_policy_cases.json`，覆盖：

- 未拆封无理由；
- 已拆封、已使用；
- 定制刻字、软件授权和已激活电子设备；
- 质量问题人工核验；
- 超期；
- 未签收；
- 商品已在退货流程。

## 指标

| 维度 | 指标 | 目标 |
|---|---|---|
| 检索 | 证据命中率 | 核心政策问题达到人工约定阈值 |
| 回答 | 引用与政策版本正确率 | 不使用无来源硬结论 |
| 决策 | 黄金用例一致率 | 100% |
| 写入 | 未确认写入 | 0 |
| 写入 | 重复申请 | 0 |
| 写入 | 越权写入 | 0 |
| 安全 | 错误令牌被接受 | 0 |
| 安全 | 提交前状态变化仍执行 | 0 |
| 对话 | 成功率与澄清轮数 | 对成功场景统计，不用单一平均值掩盖失败 |
| 运营 | 转人工原因分布 | 可解释、可追踪 |

## 仍需补充的真实评测集

- 100 条以上真实政策问题和标准引用；
- 50 条以上真实订单状态组合；
- 临界日期：第 6 天 23:59、第 7 天 00:01；
- 商品状态含未拆封、已拆封、已使用、破损和描述不清；
- 多商品订单中不同政策和不同资格结果；
- 物流接口超时、订单服务超时、退货服务失败；
- 重复点击、并发确认、令牌篡改、跨用户确认；
- 文档提示注入、恶意用户诱导绕过规则；
- 人工转接的上下文完整性和隐私脱敏。

## 发布门槛

- 所有规则黄金用例通过；
- 所有安全关键用例通过；
- 端到端演示至少覆盖成功、拒绝、人工核验、确认失效、越权五类场景；
- 真实 LLM 端点完成 tool calling 冒烟测试；
- Milvus/Ollama 不可用时仍能完成本地降级闭环，或明确关闭演示入口；
- 政策负责人完成规则表与政策文本的一致性签字。
